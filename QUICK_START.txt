# DPS v4.5 "Persona" 快速开始指南

## 📋 项目概述

DPS v4.5 是一个动态人物画像系统，专为 ZennoDroid 设计。

**v4.5 新特性：**
- 🌐 多平台支持：Reddit + Instagram 完整互动功能
- 🧩 核心模块：HumanizationEngine, UILocator, ErrorRecovery, PlatformBase
- 🚀 编译缓存：第二次运行从 ~500ms 降至 <10ms
- 🔧 健壮的 JSON 解析器：正确处理嵌套对象和转义字符
- 📊 API 错误检测：自动检测并报告 AI API 错误

---

## 📋 第一步：配置 API Key

编辑 `Config/AIConfig.json`，将占位符替换为您的真实 API Key：

```json
{
  "models": {
    "primary": {
      "api_key": "YOUR_GEMINI_API_KEY_HERE"  ← 替换这里
    }
  }
}
```

获取 API Key:
- Gemini: https://aistudio.google.com/apikey
- OpenAI: https://platform.openai.com/api-keys

### 2.2 创建 Own Code 动作

将以下文件的**完整代码**复制到 ZennoDroid 的 "Own Code" 动作块中：

1. `ZDProjects/Initializer_OwnCode.cs` → 创建"初始化"动作
2. `ZDProjects/Main_OwnCode.cs` → 创建"主入口"动作
3. `ZDProjects/PersonaCreate_OwnCode.cs` → 创建"画像生成"动作
4. `ZDProjects/DailyUpdate_OwnCode.cs` → 创建"每日更新"动作
5. `ZDProjects/SessionRunner_OwnCode.cs` → 创建"会话执行"动作

## 📋 第三步：运行顺序

### 首次运行（新画像）

```
1. [初始化] Initializer → 创建目录结构
2. [手动] 设置 project_root 和 device_id 变量
3. [主入口] Main → 返回 "NEED_CREATE_PERSONA"
4. [画像生成] PersonaCreate → 调用AI生成画像
5. [主入口] Main → 返回 "READY"
6. [会话执行] SessionRunner → 执行模拟会话
```

### 日常运行

```
1. Main → 加载配置 + 检查每日更新
   ├─ 如果返回 "NEED_DAILY_UPDATE"
   │  └─ 执行 DailyUpdate
   └─ 返回 "READY"
2. SessionRunner → 执行会话
```

## ⚠️ 常见问题

### Q: 代码在 Visual Studio 中显示错误

这是正常的！Own Code 不是标准 C# 语法：
- 没有 `using` 语句
- 没有 `class` 定义
- 使用 `Func<>` / `Action<>` 委托

只需复制粘贴到 ZennoDroid 即可正常运行。

### Q: 提示 "IZennoPosterProjectModel 找不到"

在编辑器中会显示此错误，但在 ZennoDroid 运行时会正确识别。

### Q: API 调用失败

1. 检查 `Config/AIConfig.json` 中的 API Key 是否正确
2. 确认网络连接正常
3. 查看 ZennoDroid 日志获取详细错误

### Q: 变量未设置错误

确保在 ZennoDroid 中**预先创建**所有需要的变量（见 VARIABLES.md）。
