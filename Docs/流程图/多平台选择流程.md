# 多平台选择流程 (v4.5)

## 概述

DPS v4.5 支持多平台操作，通过 `device_app_mapping.json` 配置设备与平台的映射关系，SessionRunner 在运行时动态选择并加载对应的平台模块。

---

## 流程图

```mermaid
flowchart TD
    START([SessionRunner 启动]) --> READ_DEVICE[读取 device_id]
    
    READ_DEVICE --> LOAD_MAPPING[加载 device_app_mapping.json]
    
    LOAD_MAPPING --> QUERY{查询设备映射}
    
    QUERY -->|找到| GET_PLATFORM[获取平台标识<br/>reddit/instagram]
    QUERY -->|未找到| DEFAULT[使用默认平台<br/>reddit]
    
    GET_PLATFORM --> SET_VAR[设置 current_platform 变量]
    DEFAULT --> SET_VAR
    
    SET_VAR --> LOAD_CONFIG[加载 PlatformsConfig.json]
    
    LOAD_CONFIG --> GET_MODULE_PATH[获取平台模块路径<br/>Platforms/{platform}/{platform}Module.cs]
    
    GET_MODULE_PATH --> LOAD_MODULE{加载平台模块}
    
    LOAD_MODULE -->|成功| INIT_PLATFORM[初始化平台模块<br/>PlatformModule.Initialize]
    LOAD_MODULE -->|失败| ERROR([ERROR: 模块加载失败])
    
    INIT_PLATFORM --> GET_RATE_LIMIT[获取速率限制配置]
    
    GET_RATE_LIMIT --> READY([平台就绪<br/>开始执行动作])
    
    style START fill:#90EE90
    style READY fill:#90EE90
    style ERROR fill:#FF6B6B
```

## 配置文件结构

### device_app_mapping.json

```json
{
    "mappings": [
        {
            "device_id": "Device_001",
            "platform": "reddit",
            "account_id": "user_reddit_001"
        },
        {
            "device_id": "Device_002",
            "platform": "instagram",
            "account_id": "user_ig_001"
        },
        {
            "device_id": "Device_003",
            "platform": "reddit",
            "account_id": "user_reddit_002"
        }
    ],
    "default_platform": "reddit"
}
```

### PlatformsConfig.json (平台配置)

```json
{
    "platforms": {
        "reddit": {
            "enabled": true,
            "module_path": "Platforms/Reddit/RedditModule.cs",
            "rate_limits": {
                "actions_per_hour": -1,
                "likes_per_hour": -1,
                "comments_per_hour": -1
            },
            "supported_actions": ["browse", "read", "like", "comment", "follow", "share"]
        },
        "instagram": {
            "enabled": true,
            "module_path": "Platforms/Instagram/InstagramModule.cs",
            "rate_limits": {
                "actions_per_hour": 60,
                "likes_per_hour": 30,
                "comments_per_hour": 10
            },
            "supported_actions": ["browse", "read", "like", "comment", "follow", "share"]
        }
    }
}
```

## 平台模块接口

所有平台模块必须实现 `PlatformBase` 定义的标准接口：

```csharp
// PlatformBase.cs 定义的接口
public interface IPlatformModule
{
    string Initialize(object project);
    string Browse(string paramsJson);
    string Read(string paramsJson);
    string Like(string paramsJson);
    string Comment(string paramsJson);
    string Follow(string paramsJson);
    string Share(string paramsJson);
}
```

## 平台选择逻辑 (伪代码)

```csharp
// SessionRunner.cs 中的平台选择逻辑

// 1. 读取设备ID
string deviceId = CoreHelper.GetVar("device_id");

// 2. 加载映射配置
string mappingJson = FileHelper.ReadFile(projectRoot + "Config\\device_app_mapping.json");

// 3. 查找设备对应的平台
string platform = "reddit"; // 默认值
// ... 解析 JSON 查找 device_id 对应的 platform

// 4. 设置当前平台变量
CoreHelper.SetVar("current_platform", platform);

// 5. 加载平台配置
string platformsConfigJson = FileHelper.ReadFile(projectRoot + "Config\\PlatformsConfig.json");

// 6. 获取模块路径
string modulePath = JsonHelper.GetValue(platformsConfigJson, "platforms." + platform + ".module_path");

// 7. 加载并初始化平台模块
string fullPath = projectRoot + modulePath;
// ... 动态编译并加载模块
```

## 支持的平台

| 平台 | 状态 | 模块路径 | 速率限制 |
