# 每日更新流程 (v4.5)

## 流程图

```mermaid
flowchart TD
    Start([开始]) --> Load[加载画像 persona_json]
    
    Load --> UpdateDate[更新日期相关字段]
    
    UpdateDate --> UpdatePreg{是否怀孕?}
    
    UpdatePreg -->|是| CalcWeek[计算当前孕周]
    UpdatePreg -->|否| UpdateChildren[更新孩子月龄]
    
    CalcWeek --> DetermineStage[判断阶段码]
    UpdateChildren --> DetermineStage
    
    DetermineStage --> UpdateStage[更新 maternal_stage]
    
    UpdateStage --> UpdateBehavior[更新行为参数]
    
    UpdateBehavior --> UpdateConcerns[更新 current_concerns]
    
    UpdateConcerns --> UpdateExt{需要更新扩展?}
    
    UpdateExt -->|是| CallIP[查询IP信息]
    UpdateExt -->|否| Save
    
    CallIP --> CallWeather[查询天气]
    CallWeather --> UpdateExtensions[更新 _extensions]
    UpdateExtensions --> Save
    
    Save[保存画像 + 备份] --> End([结束])
```

## 阶段判断逻辑

```mermaid
flowchart TD
    Check{is_pregnant?}
    
    Check -->|true| PregnantFlow
    Check -->|false| NotPregnantFlow
    
    subgraph PregnantFlow[怀孕阶段]
        W1{孕周 <= 13?}
        W1 -->|是| T1[T1: 孕早期]
        W1 -->|否| W2{孕周 <= 27?}
        W2 -->|是| T2[T2: 孕中期]
        W2 -->|否| T3[T3: 孕晚期]
    end
    
    subgraph NotPregnantFlow[非怀孕阶段]
        C1{有孩子?}
        C1 -->|否| TTC[TTC: 备孕期]
        C1 -->|是| C2{最小孩子月龄}
        C2 -->|<= 3月| PP0[PP0: 产后早期]
        C2 -->|4-12月| PP1[PP1: 产后中期]
        C2 -->|> 12月| NP[NP: 育儿期]
    end
```

## 更新的字段

| 字段 | 更新内容 |
|------|----------|
| `_meta.last_updated` | 当前日期 |
| `seasonal_context.current_season` | 季节 |
| `pregnancy_status.current_week` | 孕周 |
| `children[].current_age_months` | 孩子月龄 |
| `maternal_stage.stage_code` | 阶段码 |
| `behavioral_modifiers.*` | 行为参数 |
| `current_concerns` | 当前关注点 |
| `_computed.*` | 计算字段 |
