# 会话执行流程 (v4.5)

## 流程图

```mermaid
flowchart TD
    Start([开始]) --> CheckOnline{应该在线?}
    
    CheckOnline -->|否| Skip[跳过本次会话]
    CheckOnline -->|是| SelectPlatform[选择平台 v4.5]
    
    SelectPlatform --> GenPlan[生成会话计划]
    
    GenPlan --> CalcDuration[计算会话时长]
    CalcDuration --> CalcActions[计算动作分布]
    
    CalcActions --> SelectProfile[选择行为配置文件 v4.5]
    
    SelectProfile --> Loop[进入主循环]
    
    Loop --> SelectAction[选择下一个动作]
    
    SelectAction --> Execute{执行动作}
    
    Execute -->|browse| DoBrowse[浏览帖子]
    Execute -->|read| DoRead[阅读帖子]
    Execute -->|like| DoLike[点赞]
    Execute -->|comment| DoComment[评论]
    Execute -->|follow| DoFollow[关注 v4.5]
    Execute -->|share| DoShare[分享 v4.5]
    
    DoBrowse --> Humanize[人性化延迟 v4.5]
    DoRead --> Humanize
    DoLike --> Humanize
    DoComment --> Humanize
    DoFollow --> Humanize
    DoShare --> Humanize
    
    Humanize --> ErrorCheck{操作成功?}
    
    ErrorCheck -->|否| Retry[错误恢复 v4.5]
    ErrorCheck -->|是| LogAction
    
    Retry --> RetryCheck{重试次数 < 3?}
    RetryCheck -->|是| Execute
    RetryCheck -->|否| LogAction
    
    LogAction[记录到 Memory] --> RateLimit{速率限制检查 v4.5}
    
    RateLimit -->|超限| Wait[等待冷却]
    RateLimit -->|正常| CheckTime
    
    Wait --> CheckTime{时间用完?}
    
    CheckTime -->|否| Loop
    CheckTime -->|是| SaveState[保存状态]
    
    Skip --> End([结束])
    SaveState --> End
```

## v4.5 新增：行为配置文件

```mermaid
pie title 行为配置文件分布
    "casual (默认)" : 50
    "lurker" : 25
    "active" : 15
    "new_user" : 10
```

| 配置文件 | 滚动速度 | 阅读时间 | 暂停频率 |
|----------|----------|----------|----------|
| active | 快 | 短 | 低 |
| casual | 中 | 中 | 中 |
| lurker | 慢 | 长 | 高 |
| new_user | 中慢 | 中长 | 中高 |
