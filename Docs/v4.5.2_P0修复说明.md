## 1. ModuleLoader.cs - 缓存管理优化

### 问题描述
- **缓存失效不检测依赖文件删除**: 删除依赖文件后仍使用旧编译结果，导致行为与源码不一致
- **缓存无界增长**: 静态字典永不清理，长期运行导致内存泄漏

### 修复方案
```csharp
// 引入结构化缓存条目
class CacheEntry
{
    public System.Reflection.MethodInfo Method;
    public System.Collections.Generic.Dictionary<string, long> DependencyTimestamps;
    public System.DateTime LastAccess;
}

// LRU 缓存淘汰
const int MAX_CACHE_ENTRIES = 32;
```

### 关键改进
1. **依赖快照**: 缓存包含完整依赖文件列表和时间戳
2. **删除检测**: 对比缓存快照与当前文件列表，检测删除
3. **路径规范化**: `NormalizeDependencyPath` 避免大小写/分隔符导致重复键
4. **LRU 淘汰**: 超过 32 个条目自动清理最旧缓存

### 影响
- ✅ 消除"幽灵代码"问题（使用已删除文件的旧编译结果）
- ✅ 防止长期运行内存泄漏
- ✅ 提升缓存可靠性

## 2. SessionRunner.cs - 并发安全性

### 问题描述
- **静态状态跨会话串扰**: `_random` 和 `_energy` 等静态变量被多会话共享
- **配置异常导致崩溃**: `GetActionDelay` 在 min/max 颠倒时抛异常

### 修复方案
```csharp
// 线程安全的随机数生成器
[System.ThreadStatic]
private static Random _threadRandom;

private static Random GetRandom()
{
    if (_threadRandom == null)
    {
        _threadRandom = new Random(unchecked(
            Environment.TickCount * 31 + 
            System.Threading.Thread.CurrentThread.ManagedThreadId
        ));
    }
    return _threadRandom;
}

// 疲劳模型状态封装
private class SessionState
{
    public bool FatigueEnabled;
    public double Energy;
    public double DecayBrowse;
    public double DecayRead;
    public double DecayLike;
    public double DecayComment;
    public double RecoveryPerPauseSec;
    public double MinEnergyToComment;
    public double MinEnergyToLike;
}
```

### 关键改进
1. **ThreadStatic 随机数**: 每个线程独立的随机数生成器
2. **SessionState 封装**: 疲劳模型状态改为实例字段
3. **配置容错**: `GetActionDelay` 添加边界校验和溢出保护

### 影响
- ✅ 消除多会话互相干扰
- ✅ 行为可复现
- ✅ 防止配置错误导致崩溃

## 3. MemoryManager.cs - 并发写入保护

### 问题描述
- **并发写入丢数据**: 无锁 read-modify-write 竞态，多会话同时写入导致记录丢失

### 修复方案
```csharp
private static readonly object _locksGuard = new object();
private static readonly Dictionary<string, object> _fileLocks = new Dictionary<string, object>();

private static object GetFileLock(string path)
{
    lock (_locksGuard)
    {
        object fileLock;
        if (!_fileLocks.TryGetValue(path, out fileLock))
        {
            fileLock = new object();
            _fileLocks[path] = fileLock;
        }
        return fileLock;
    }
}

// 使用文件级锁保护写入
object fileLock = GetFileLock(memoryFilePath);
lock (fileLock)
{
    // 读改写操作
}
```

### 关键改进
1. **文件级锁**: 按文件路径获取独立锁对象
2. **原子操作**: 读改写操作在锁保护下执行

### 影响
- ✅ 消除并发写入丢数据风险
- ✅ 保证交互记录完整性
- ✅ 去重和统计准确性

## 4. DailyUpdate.cs - 数据完整性

### 问题描述
- **未来 conception_date 产生负孕周**: 时区/录入错误导致负值，画像出现不可能状态
- **缺少产后阶段转换**: 只覆盖 T1/T2/T3，无法进入 PP0/PP1/NP

### 修复方案
```csharp
// 边界校验
int totalDays = (int)(DateTime.Now - conceptionDate).TotalDays;

if (totalDays < 0)
{
    CoreHelper.LogErr(TAG, "conception_date 在未来，跳过孕周更新");
    CoreHelper.SetVar("last_error", "conception_date_future");
}
else
{
    int weeks = totalDays / 7;
    int days = totalDays % 7;
    
    if (weeks < 0) weeks = 0;
    if (days < 0) days = 0;
    // ...
}

// 产后阶段转换
if (currentStage == "PP0" || currentStage == "PP1")
{
    var deliveryMatch = Regex.Match(personaJson, "\"delivery_date\"\\s*:\\s*\"([^\"]+)\"");
    if (deliveryMatch.Success)
    {
        DateTime deliveryDate;
        if (DateTime.TryParse(deliveryMatch.Groups[1].Value, out deliveryDate))
        {
            int monthsSinceDelivery = ((DateTime.Now.Year - deliveryDate.Year) * 12) + 
                                      DateTime.Now.Month - deliveryDate.Month;
            
            string newStage = currentStage;
            if (currentStage == "PP0" && monthsSinceDelivery >= 3)
            {
                newStage = "PP1";
            }
            else if (currentStage == "PP1" && monthsSinceDelivery >= 12)
            {
                newStage = "NP";
            }
            // ...
        }
    }
}
```

### 关键改进
1. **未来日期检测**: `totalDays < 0` 跳过更新并记录错误
2. **负值保护**: weeks/days 归零
3. **产后阶段转换**: PP0 → PP1（3个月）→ NP（12个月）

### 影响
- ✅ 消除负孕周问题
- ✅ 补齐产后阶段生命周期
- ✅ 画像数据完整性
