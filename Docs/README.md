A: 如果你是新手，从 [GETTING_STARTED.md](GETTING_STARTED.md) 开始。

A: 在 [DPS_v4.5_完整配置手册.md](DPS_v4.5_完整配置手册.md) 的第2-3章。

**Q: 遇到不懂的术语怎么办？**
A: 查阅 [GLOSSARY.md](GLOSSARY.md)。

**Q: 想了解某个模块的详细流程？**
A: 查看 `流程图/` 目录下对应的文件。
