# DPS v4.5 子项目调用架构

> 版本: v3.1 - v4.5.2 Updated
> 更新日期: 2026-02-14

---

## 一、架构概述

DPS 采用 **主项目 + 子项目** 的分层架构：

| 层级 | 格式 | 职责 |
|------|------|------|
| **主项目** | `.droid` | 流程控制、决策调度 |
| **子项目** | `.droid` | 拟人化 UI 操作（点击、拖拽、滑动） |
| **C# 模块** | `.cs` | 画像、记忆、AI 决策逻辑 |

**为什么这样设计**：
- ZD 的拟人化操作（点击、拖拽）必须在 .droid 中实现
- C# 代码不便于维护复杂的 UI 操作
- 子项目之间需要相互调用（如浏览时发现好帖子 → 阅读）

## 三、调用流程（多平台版）

### 3.1 主流程

```
┌─────────────────────────────────────────────────────────────────┐
│                     MainProject.droid                            │
├─────────────────────────────────────────────────────────────────┤
│  [1] Own Code: SessionRunner.cs                                  │
│      ├── 读取 device_id                                          │
│      ├── DeterminePlatform() → 查询 device_app_mapping.json      │
│      ├── LoadPlatformModule() → 加载平台模块                     │
│      │   ├── Reddit → Platforms/Reddit/RedditModule.cs           │
│      │   ├── Instagram → Platforms/Instagram/InstagramModule.cs  │
│      │   ├── TikTok → Platforms/TikTok/TikTokModule.cs           │
│      │   └── Facebook → Platforms/Facebook/FacebookModule.cs     │
│      ├── 根据画像 + 平台配置决定动作序列                          │
│      ├── 设置 action_type = "browse"                             │
│      ├── 设置 action_params_json = "{...}"                       │
│      └── 返回 session_result = "CALL_PLATFORM_MODULE"            │
├─────────────────────────────────────────────────────────────────┤
│  [2] 调用平台模块操作                                            │
│      ├── "initialize" → PlatformModule.Initialize()              │
│      ├── "browse"     → PlatformModule.Browse()                  │
│      ├── "like"       → PlatformModule.Like()                    │
│      ├── "comment"    → PlatformModule.Comment()                 │
│      ├── "follow"     → PlatformModule.Follow()                  │
│      ├── "share"      → PlatformModule.Share()                   │
│      └── "done"       → 跳过，进入下一步                          │
├─────────────────────────────────────────────────────────────────┤
│  [3] 平台模块内部（以Instagram为例）                             │
│      ├── 检查速率限制 (60 actions/hour, 30 likes/hour)           │
│      ├── 使用 HumanizationEngine 生成拟人化行为                  │
│      ├── 使用 UILocator 定位UI元素                               │
│      ├── 执行操作（点击、滑动、输入）                             │
│      ├── 使用 ErrorRecovery 处理错误（最多3次重试）              │
│      └── 返回标准化结果: {success, message, data, duration_ms}   │
├─────────────────────────────────────────────────────────────────┤
│  [4] 循环检查 (检查 next_action)                                 │
│      ├── next_action != "none" → 回到步骤 [2]                    │
│      └── next_action == "none" → 继续主流程                      │
├─────────────────────────────────────────────────────────────────┤
│  [5] Own Code: StateSaver.cs                                     │
│      └── 保存会话记忆（跨平台）                                  │
└─────────────────────────────────────────────────────────────────┘
```

### 3.2 子项目内部流程

以 `Browse.droid` 为例：

```
┌─────────────────────────────────────────────────────────────────┐
│                      Browse.droid                                │
├─────────────────────────────────────────────────────────────────┤
│  [1] 读取参数                                                    │
│      └── 从 action_params_json 获取浏览时长、目标等               │
├─────────────────────────────────────────────────────────────────┤
│  [2] 执行浏览操作 (ZD 拟人化)                                    │
│      ├── 滑动浏览帖子列表                                        │
│      ├── 随机停留查看                                            │
│      └── 记录看到的帖子                                          │
├─────────────────────────────────────────────────────────────────┤
│  [3] 发现符合条件的帖子？                                        │
│      ├── 是 → 设置 found_post_id, next_action = "read"           │
│      └── 否 → 设置 next_action = "none"                          │
├─────────────────────────────────────────────────────────────────┤
│  [4] 记录行为                                                    │
│      └── 追加到 action_log_json                                  │
├─────────────────────────────────────────────────────────────────┤
│  [5] 设置结果                                                    │
│      └── action_result = "SUCCESS"                               │
└─────────────────────────────────────────────────────────────────┘
```

### 3.3 子项目相互调用

**场景**：浏览时发现好帖子 → 阅读 → 点赞

```
Browse.droid
    │
    ├── 发现好帖子
    ├── 设置 found_post_id = "post_123"
    ├── 设置 next_action = "read"
    └── 返回主项目
            │
            ▼
MainProject.droid (循环检查)
    │
    ├── next_action == "read"
    └── 执行 ReadPost.droid
            │
            ▼
ReadPost.droid
    │
    ├── 读取 found_post_id
    ├── 执行阅读操作
    ├── 决定是否点赞
    ├── 设置 next_action = "like" 或 "none"
    └── 返回主项目
            │
            ▼
MainProject.droid (循环检查)
    │
    └── ... 继续或结束
```

## 四、变量约定

### 4.1 动作控制变量

| 变量名 | 类型 | 用途 | 示例值 |
|--------|------|------|--------|
| `action_type` | String | 当前要执行的动作 | `browse`, `read`, `like` |
| `action_params_json` | String | 动作参数 (JSON) | `{"duration": 30}` |
| `action_result` | String | 动作执行结果 | `SUCCESS`, `ERROR` |
| `next_action` | String | 下一个动作 | `read`, `like`, `none` |

### 4.2 数据传递变量

| 变量名 | 类型 | 用途 | 示例值 |
|--------|------|------|--------|
| `found_post_id` | String | 发现的帖子 ID | `post_12345` |
| `found_post_title` | String | 帖子标题 | `"求推荐婴儿车"` |
| `found_user_id` | String | 发现的用户 ID | `user_789` |
| `action_log_json` | String | 本次会话的行为日志 | `[{...}, {...}]` |

### 4.3 上下文变量

| 变量名 | 类型 | 用途 | 示例值 |
|--------|------|------|--------|
| `current_screen` | String | 当前屏幕状态 | `home`, `post_detail` |
| `session_start_time` | String | 会话开始时间 | `2026-02-05T10:30:00` |
| `actions_completed` | String | 已完成动作数 | `5` |

## 六、SessionRunner 决策逻辑

```csharp
// SessionRunner.cs 核心逻辑

// 1. 根据画像和配置生成动作序列
List<string> plannedActions = GenerateActionSequence(persona, behaviorConfig);
// 例如: ["browse", "browse", "read", "like", "browse"]

// 2. 取出下一个动作
string nextAction = GetNextAction(plannedActions, actionsCompleted);

// 3. 生成动作参数
string paramsJson = GenerateActionParams(nextAction, persona);

// 4. 设置变量
CoreHelper.SetVar("action_type", nextAction);
CoreHelper.SetVar("action_params_json", paramsJson);

// 5. 返回状态
if (nextAction != "done")
{
    return "CALL_SUBPROJECT";
}
else
{
    return "SESSION_COMPLETE";
}
```

## 七、子项目开发规范

### 7.1 必须实现的步骤

每个子项目必须包含：

1. **读取参数** - 从 `action_params_json` 获取配置
2. **执行操作** - ZD 拟人化操作
3. **记录行为** - 追加到 `action_log_json`
4. **设置结果** - `action_result` = SUCCESS/ERROR
5. **设置下一步** - `next_action` = 下一个动作或 "none"

### 7.2 错误处理

```
如果操作失败：
├── 设置 action_result = "ERROR"
├── 设置 last_error = "错误描述"
├── 设置 next_action = "none"
└── 返回主项目（主项目决定是否重试）
```

### 7.3 超时处理

每个子项目应设置合理的超时时间，避免卡死。
