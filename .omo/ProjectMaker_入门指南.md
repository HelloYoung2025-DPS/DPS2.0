# ProjectMaker 基础操作入门指南

> 从零开始，一步步教你在 ProjectMaker 中搭建自动化流程
> 适用于从未使用过 ProjectMaker 的用户

---

## 一、界面认识

打开 ProjectMaker 后，你会看到这样的布局：

```
+------------------------------------------------------------------+
|  菜单栏: File  Edit  View  Tools  Help                            |
+----------+---------------------------+--------------------------+
|          |                           |                          |
|  左侧    |     中间工作区             |   右侧                   |
|  动作    |    （画布/流程图）          |   属性面板                |
|  面板    |                           |   变量面板                |
|          |   这里放你的动作块          |   日志面板                |
|  分类:   |   用线连起来               |                          |
|  Android |                           |                          |
|  逻辑    |   [START]                 |                          |
|  数据    |      |                    |                          |
|  图像    |      v                    |                          |
|  ...     |   [动作块1]               |                          |
|          |      |                    |                          |
|          |      v                    |                          |
|          |   [END]                   |                          |
+----------+---------------------------+--------------------------+
|  底部: 设备连接状态 | 模拟器屏幕预览                               |
+------------------------------------------------------------------+
```

### 关键区域

| 区域 | 在哪里 | 做什么用 |
|---|---|---|
| **左侧动作面板** | 窗口最左边，有分类列表 | 所有可用的动作块都在这里，按分类排列 |
| **中间工作区** | 窗口正中间，最大的区域 | 你的"画布"，在这里拖放和连接动作块 |
| **右侧属性面板** | 窗口右边 | 点击某个块后，这里显示它的配置选项 |
| **变量面板** | 通常在右下角，或通过菜单 Window → Variables 打开 | 管理项目中的变量 |
| **底部工具栏** | 窗口最下方 | 显示设备连接状态、运行按钮、模拟器屏幕 |
| **模拟器预览** | 底部或侧边（取决于布局） | 实时显示连接的 Android 设备屏幕 |

## 二、第一步：创建新项目

1. 菜单: **File → New** （或 Ctrl+N）
2. 弹出保存对话框 → 选个位置 → 输入文件名，比如 `Phase0_Test` → 保存
3. 工作区中会出现一个 **[START]** 块（绿色圆点），这是流程的起点

---

## 三、第二步：连接设备

ProjectMaker 需要连接一台 Android 设备（真机或模拟器）才能运行。

### 如果用真机（你的 R58M255GNQZ 设备）

1. 确保手机通过 USB 连接电脑
2. 手机开启 USB 调试
3. 在 ProjectMaker 底部看设备状态：
   - 绿色 = 已连接
   - 红色/灰色 = 未连接
4. 如果未连接，点击底部的设备按钮 → 选择你的设备

### 如果用模拟器

1. 先启动模拟器（MEmu/LDPlayer/BlueStacks）
2. ProjectMaker 会自动检测已启动的模拟器
3. 在设备列表中选择它

---

## 四、第三步：添加动作块（3 种方式）

### 方式 A：从左侧面板拖拽（最常用）

```
左侧面板            中间工作区
+----------+        +------------------+
| Android  |        |                  |
|  ├ 应用   |  拖→   |   [打开应用]       |
|  ├ 工具   |        |                  |
|  └ 设置   |        |                  |
| 逻辑     |        |                  |
|  ├ If    |        |                  |
|  ├ Switch|        |                  |
|  └ Pause |        |                  |
+----------+        +------------------+
```

1. 在左侧找到你要的分类（如 Android → 应用管理）
2. 找到具体动作（如"打开应用"）
3. 按住左键拖到工作区的空白处
4. 松开，动作块出现在工作区

### 方式 B：右键菜单添加

1. 在工作区空白处**右键**
2. 弹出菜单 → **Add Action**（或 "添加动作"）
3. 从子菜单中选择分类和具体动作

### 方式 C：录制操作（自动生成块）

1. 点击工具栏的**录制**按钮（红色圆点图标）
2. 在模拟器/设备屏幕上手动操作（点击、滑动等）
3. 每个操作会自动在工作区生成一个对应的动作块
4. 点击**停止录制**
5. 然后你可以微调自动生成的块的参数

---

## 五、第四步：配置动作块的属性

每个动作块都有自己的配置项。

### 打开属性

**双击**工作区中的动作块 → 弹出属性配置窗口

### 常见属性字段

| 字段名 | 含义 | 例子 |
|---|---|---|
| Package name | APP 包名 | `com.android.settings` |
| XPath | 元素查找表达式 | `//*[@text="Settings"]` |
| Text | 文本内容 | `Hello World` |
| X / Y | 屏幕坐标 | `540` / `1200` |
| Wait / Duration | 等待时间(毫秒) | `3000` |
| Variable | 保存结果的变量名 | `test_result` |

### 在属性中引用变量

如果某个字段需要动态值，用这个格式：

```
{-Variable.变量名-}
```

比如：
- 等待时间想用变量控制：填 `{-Variable.zd_wait_ms-}`
- 输入文本想用变量：填 `{-Variable.zd_text-}`
- APP 包名想用变量：填 `{-Variable.target_app-}`

---

## 六、第五步：连线（决定执行顺序）

动作块之间需要用线连起来，告诉 ZD 执行顺序。

### 每个块有 3 种端口

```
        [输入端口]  ← 从上一个块接收执行流
            |
    +-------+-------+
    |   动作块名称    |
    +-------+-------+
       |         |
  [绿色端口]  [红色端口]
   (成功时)    (失败时)
```

- **输入端口**（顶部）：接收上一个块的连线
- **绿色端口 (Good)**（底部左）：这个块**成功执行后**走这条线
- **红色端口 (Bad)**（底部右）：这个块**执行失败后**走这条线

### 如何连线

1. 鼠标移到一个块的**输出端口**（绿色或红色小圆点）
2. 按住左键**拖拽**到下一个块的**输入端口**
3. 松开，线就连好了

### 连线示例

```
[START]
   |
   v (绿色线)
[打开应用: Settings]
   |           \
   v (绿色)    v (红色)
[点击搜索]    [通知: 打开失败]
   |               |
   v               v
  ...            [END]
```

- 打开成功 → 走绿线 → 继续点击搜索
- 打开失败 → 走红线 → 通知失败 → 结束

---

## 七、第六步：创建变量

变量用来在不同动作块之间传递数据。

### 打开变量面板

菜单: **Window → Variables**

### 创建变量

1. 在变量面板中，选择 **Custom** 标签（自定义变量）
2. 点击 **Add** 按钮（或 + 图标）
3. 填写：
   - **Name**：变量名（英文，无空格），如 `test_result`
   - **Value**：默认值，如 `0` 或留空
4. 点击确认

### 使用变量

| 场景 | 语法 |
|---|---|
| 在动作块属性字段中 | `{-Variable.test_result-}` |
| 在 C# 代码块中读取 | `project.Variables["test_result"].Value` |
| 在 C# 代码块中写入 | `project.Variables["test_result"].Value = "新值";` |

---

## 八、第七步：添加 C# 代码块

C# 代码块让你用代码做更复杂的事。

### 添加方式

左侧面板 → **逻辑** 分类 → 找到 **Custom code** 或 **C# 代码块** → 拖到工作区

或者：工作区右键 → Add Action → 找 Custom code / C# code

### 编写代码

双击 C# 代码块 → 弹出代码编辑器 → 写代码

### 常用代码模板

```csharp
// 1. 往日志输出信息（在 ProjectMaker 底部日志面板显示）
project.SendInfoToLog("你好，这是一条日志", true);

// 2. 读取变量
string val = project.Variables["test_result"].Value;

// 3. 设置变量
project.Variables["test_result"].Value = "成功";

// 4. 获取设备输入接口（用于 Tap/Swipe）
var input = instance.DroidInstance.Input;
input.Tap(540, 1200);           // 点击坐标
input.Swipe(540, 1600, 540, 800, 500);  // 滑动

// 5. 获取屏幕 UI 布局（XML 格式）
string xml = instance.DroidInstance.Hierarchy.GetLayout();

// 6. 按返回键
instance.DroidInstance.Input.Shell("input keyevent 4");

// 7. 等待
System.Threading.Thread.Sleep(2000);  // 等 2 秒
```

## 九、第八步：运行和调试

### 运行整个流程

工具栏上有运行按钮（三角形 Play 图标），点击后从 [START] 开始执行全部流程。

### 单步调试

1. 工具栏找到 **"下一步"** 按钮（通常是一个带箭头的图标）
2. 每点一次，执行一个动作块
3. 当前正在执行的块会**高亮**
4. 可以在变量面板实时看到变量值的变化

### 设置断点

1. 在某个动作块上**双击左边缘**（或右键 → 设置断点）
2. 该块会出现一个红色圆点标记
3. 运行时会在这个块**暂停**，等你手动继续

### 查看日志

- 底部日志面板会显示每个块的执行结果
- `project.SendInfoToLog()` 输出的内容也在这里
- 红色 = 错误，黄色 = 警告，白色 = 信息

## 十、第九步：保存项目

- **Ctrl+S** 或 File → Save
- 项目保存为 `.xmlz` 文件
- 这个文件可以在 ZennoDroid（执行环境）中加载运行

## 十一、实战练习：你的第一个流程

跟着做一遍，确认你掌握了基本操作。

### 目标
打开设置 APP → 等 3 秒 → 输出一条日志 → 关闭设置

### 操作

**第 1 步：创建项目**
- File → New → 保存为 `MyFirstProject`

**第 2 步：添加"打开应用"块**
- 左侧面板: Android → 应用管理 → 打开应用
- 拖到工作区
- 双击配置: Package name = `com.android.settings`，Wait after = `3000`

**第 3 步：添加"等待"块**
- 左侧面板: 逻辑 → Pause (等待)
- 拖到工作区
- 双击配置: 时间 = `3000`

**第 4 步：添加"C# 代码"块**
- 左侧面板: 逻辑 → Custom code
- 拖到工作区
- 双击写代码:
```csharp
project.SendInfoToLog("我的第一个流程执行成功!", true);
```

**第 5 步：添加"关闭应用"块**
- 左侧面板: Android → 应用管理 → 关闭应用
- 拖到工作区
- 双击配置: Package name = `com.android.settings`

**第 6 步：连线**
```
[START] ——绿线——→ [打开应用] ——绿线——→ [等待] ——绿线——→ [C#代码] ——绿线——→ [关闭应用] ——绿线——→ [END]
```

从 START 的输出端口拖线到"打开应用"的输入端口，
从"打开应用"的绿色端口拖线到"等待"的输入端口，
依次类推。

**第 7 步：运行**
- 确保设备已连接（底部状态绿色）
- 点击运行按钮
- 观察：设置 APP 被打开 → 等 3 秒 → 日志显示"执行成功" → 设置关闭

**第 8 步：确认日志**
- 底部日志面板应该显示: `我的第一个流程执行成功!`

## 十二、常用动作块速查表

| 你想做什么 | 去哪里找 | 块名称 |
|---|---|---|
| 打开一个 APP | Android → 应用管理 | 打开应用 (Open App) |
| 关闭一个 APP | Android → 应用管理 | 关闭应用 (Close App) |
| 点击屏幕某处 | Android → 执行事件 | 执行事件 (Execute Event) → Click |
| 滑动屏幕 | Android → 执行事件 | 执行事件 (Execute Event) → Swipe |
| 输入文字 | Android → 设置值 | 设置值 (Set Value) |
| 读取元素文本 | Android → 获取值 | 获取值 (Get Value) |
| 检查屏幕文字 | Android → 工具 | 文本检查 (Text Check) |
| 执行 ADB 命令 | Android → 工具 | ADB Shell |
| 截图 | 通过 ADB Shell | `screencap -p /sdcard/screenshot.png` |
| 等待/暂停 | 逻辑 → Pause | 等待 (Pause) |
| 条件判断 | 逻辑 → If | If 条件 |
| 多分支选择 | 逻辑 → Switch | Switch 分支 |
| 写 C# 代码 | 逻辑 → Custom code | C# 代码块 |
| 输出日志 | 逻辑 → Notification | 通知 (Notification) |
| 按 Home 键 | ADB Shell | `input keyevent 3` |
| 按 Back 键 | ADB Shell | `input keyevent 4` |
| 按 Enter 键 | ADB Shell | `input keyevent 66` |

## 十三、右键技巧

在工作区的动作块上右键，有很多实用选项：

| 选项 | 作用 |
|---|---|
| 复制 / 粘贴 | 复制一个块（含配置） |
| 删除 | 删除这个块 |
| 转换为 C# | 查看这个块等价的 C# 代码（学习用） |
| 设置断点 | 调试时暂停在这个块 |
| 禁用 | 临时跳过这个块（不删除） |
