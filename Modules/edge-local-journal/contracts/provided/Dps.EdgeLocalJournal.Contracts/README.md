# Dps.EdgeLocalJournal.Contracts

Versioned DTOs and non-secret APIs for `edge.journal.append/v1`, `edge.journal.receipt/v1`, and `edge.journal.drain.attestation/v1`.

Production consumers reference this package, use `CanonicalJson` before computing payload SHA-256, use `JournalChecksumEncoding` for the Journal checksum profile, and use `JournalDrainAttestationCodec` for strict rich-wire serialization, Journal-owned owner-receipt framing, and the single Journal public-key signature. Least-authority composition uses separate `IJournalAppendClient`, `IJournalReadiness`, `IJournalDrainAttestationProvider`, and `IJournalQuarantineAdministration` capabilities; no public aggregate interface combines them. The package does not contain `JournalStore`, the Journal signing authority, or private-key material.

The Worker receipt and Journal rich attestation are independent wires with different owners. Journal never imports, parses, reconstructs, or implements the Worker wire contract and never signs caller-provided Worker statement bytes. It re-derives the `WORKER_DRAINED` payload, scope, owner receipt, and deployment truth from durable state, then binds only `worker_receipt_wire_sha256`: the lowercase SHA-256 of the exact persisted Worker receipt UTF-8 bytes. Supervisor independently decodes and verifies the raw Worker wire with the Supervisor-owned codec, hashes those exact bytes, verifies the Journal rich wire with this package, correlates every shared scope/deployment/drain field, and rejects equal normalized Worker and Journal SPKI identities.

The narrow interfaces are compile-time capability boundaries, not same-process security isolation. A Worker that receives a concrete object implementing several interfaces can cast it. Production F6 therefore requires an independent authenticated IPC append/readiness proxy whose concrete type and dependency closure contain no `JournalStore`, attestation provider, quarantine administrator, or signing authority. Direct `JournalStore` injection is simulation-only and cannot support `WINDOWS_VERIFIED`.
