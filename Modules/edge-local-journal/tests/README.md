# Test boundaries

- `unit` (6 methods): canonical JSON, domain-separated length-prefixed checksums, strict ASCII command/entry IDs, full-scope duplicate identity, persistent conflict quarantine, monotonic sequence, caller head/range exclusion, owner-recomputed single rich Journal drain proof, opaque exact Worker-wire digest binding, and fail-closed missing authority or invalid Journal validity.
- `contract` (3 methods): exact `edge.journal.append/v1` caller provenance, exact `edge.journal.receipt/v1` Journal provenance, owner `edge.journal.drain.attestation/v1`, machine-readable checksum/auth profiles, independent Worker-wire correlation, Worker `command`/`receipt` IPC semantics with no Worker attestation edge, common identity fields, fail-closed unknown/duplicate fields, and proof that DTOs, four narrow interfaces, and the non-secret codec come from `Dps.EdgeLocalJournal.Contracts` while `JournalStore` remains a separate implementation assembly and no public aggregate exists.
- `contract-schema` (6 Python methods): validates the three provider-owned 48-case corpora (including 25 drain-attestation cases), strict ID tokens, the length-prefixed checksum profile, exact UTC wire timestamps, absolute-end digests, raw Int64 boundaries, and an independently recomputed UTF-8 framing golden vector.
- `Integration` (7 methods): durable append, two store instances serialized against one path, restart replay, persistent quarantine plus exact-digest release, scope tampering rejection, old-checksum-format rejection, hard recovery-size rejection, crash-tail isolation, restart attestation, real second-process append, identical-content replacement, symlink rebinding, intent-gate inode rebinding, and a real `AppendAsync` process killed after its flushed intent but before writer acquisition. Attestation tests use `EvidenceKind=LOCAL_PROCESS`; older recovery tests remain `SIMULATION`.

All Mac results are local integration or simulation evidence. They are not Windows evidence.
