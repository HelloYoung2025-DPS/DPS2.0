# Operations

Production lease truth is an isolated PostgreSQL 18.4 Factory schema reached with separate process credentials. `PostgresLeaseStore` uses database transactions, per-idempotency and per-lock advisory locks, per-module/path/contract rows, and durable monotonic fencing counters. Apply `migrations/001_external_lease_store.sql` through its explicit migration method during authorized deployment. The SQLite implementation is dev-only and cannot satisfy F3 evidence. `GitWorktreeMaterializer` is the narrow host adapter: previous-stable code binds repository/worktree roots, policy digest and test argv; the candidate supplies no command. It uses exact detached baseline worktrees, active fence facts, owned-path commits, dependency waves, fixed merges, and a required merge-head retest. `factory_revoke_all_worktree_leases` revokes authority; rollback stops materialization, retains commits/token history, and routes planning to the previous signed manager.
