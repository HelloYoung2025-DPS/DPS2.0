# Operation Compiler tests

Synthetic unit and contract tests cover the fixed action/step mapping, mandatory asynchronous authoritative-reader lookup, ACTIVE/exact-scope/digest rejection, absence of a naked-approval compile API, all approval fields committed into `approval_sha256`, shared OperationId and StepId recomputation, domain-separated length-prefixed strict-UTF-8 encoding, delimiter and replacement-fallback collisions, machine-readable golden vectors and schema-bound spec digest, explicit snake_case JSON round trips, unknown/missing/duplicate JSON rejection through the strict codec, schema/DTO property/required/cardinality agreement, deep-frozen snapshots, ID/envelope tampering, duplicate/oversized policy collections and argument enumerations, null/empty/oversized values, unknown majors, missing parameters, canonical `duration_ms` bounds, Planner-aligned opaque reference bounds, and explicit rejection of prompt/coordinate fallback. The fake authoritative reader in those suites proves fail-closed orchestration only.

The required ten-case `Integration` suite is explicitly tagged `EvidenceKind=LocalCryptographicStorageSimulation`. It creates an actual P-256 key, signs an exact canonical `approval.decision/v1` wire plus lookup scope, ACTIVE status, current status/runtime revisions, runtime-state digest and Release BOM digest, verifies the pinned public key and exact pinned state through the production asynchronous `IAuthoritativeApprovalReader` port, compiles through the real allowlist, re-enters the strict `operation.compiled/v1` codec, and hands only canonical bytes to asynchronous `ICompiledOperationCommandConsumer`. It covers forged, denied, shadow, expired, revoked and stale-state approval input; cross-Soul/device/account/trace/approval lookup; unknown major/action/step and coordinate fallback; signed malformed duration, prompt, coordinate-shaped and oversized-reference semantics; deterministic exact replay; conflicting replay quarantine; a disk-flushed pending-to-atomic-rename crash window and reconstructed restart; mutable input isolation; duplicate/noncanonical JSON and invalid UTF-8; an approval reader that ignores cancellation past the deadline; and a command consumer that completes successfully only after the deadline. Both late cases prove caller-visible success is denied and the terminal result is isolated through the required quarantine port.

This suite is not PostgreSQL, Windows, ZennoDroid, ADB, device, canary, or production-key evidence. It does not claim the test signer is `policy-approval`. Production remains blocked until the policy-owned authenticated receipt adapter is wired and independently verified.
