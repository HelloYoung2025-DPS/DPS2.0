# Planner operations

The module is proposed and not release eligible. `planner_shadow_v2` and `kill_planner` are reserved rollout identifiers; no live Control Plane or Release BOM routing is wired yet. Before release, the Control Plane/BOM controller must own those controls, prove their current state, and demonstrate routing back to the previous signed BOM. Planner itself owns no flag store, kill-switch service, outbox, or audit sink.

`planner_shadow_v2` must remain shadow-only. The current path emits only strict v2 typed-digest proposals. V1 may be decoded only by an explicitly deprecated shadow/quarantine compatibility path and must never be used as a current output, promotion input, rollback execution fallback, approval, command, device result, or integration evidence. `ProposerKind` is an untrusted classification hint, not an authenticated role; any future authorization must arrive in a separately signed Control Plane envelope. Contract failures, unknown proposer kinds/actions/fields/majors, and any identity or reference outside its fixed lowercase-hex form fail closed and emit no proposal.

The required `planner.real-local-process` suite is a development-only `REAL_LOCAL_PROCESS` boundary check. Each of its seven required cases starts an independent checked-in explicit child-process test endpoint over isolated serialized file IPC and the production Planner/v2 codec. Its forced-kill window occurs after the proposal is computed but before its wire bytes are published; restart must recompute byte-identical output from the same immutable request. The child publishes readiness by flushing a same-directory temporary file and atomically renaming it; the parent holds the `Process` handle, reads the proof through one stable handle with bounded retry, binds the reported PID and proposal digest, and verifies that exact process exits non-zero before replay. Timeout/dispose cleanup must also prove child exit. The fixture has no approval, executor, device, database, GBrain, network, or rollout authority and must never be deployed or treated as a Control Plane endpoint.
