# Persona Store migrations

`001_create_persona_store.sql` installs the PostgreSQL 18.4 vertical slice after C# atomically creates and owner-binds an absent schema. The migrator substitutes only validated, quoted schema and runtime-role identifiers. Runtime cannot execute DDL, raw table/column DML, internal helpers, key-attestation/export-receipt reads, or sequences. It receives bounded table reads and exactly six fixed `SECURITY DEFINER` entry points. The entry points use fixed `search_path`, advisory serialization, exact JSON/fence/composition checks, an immutable export receipt bound to a deployment-attested HMAC key and complete relational history, and a deferred revision/current/payload/receipt/outbox bundle.

Public revision rows hold per-Soul keyed commitments, strictly sorted allowed keys/evidence, exact fence receipt identity/sequence, Binding composition tuple, and exact identity scope. A deferred composite foreign key and bundle trigger require the exact revision, every result JSON field, database-canonical result digest, current pointer, closed-vocabulary payload/HMAC commitment, matching idempotency receipt, and matching outbox payload to commit together. Personal trait values live in a separate payload table and each Soul has an independent random HMAC key. A `deleted` tombstone removes the live-primary value/key rows and records `live-postgresql-primary-only`; this is `LIVE_PRIMARY_LOGICAL_DELETED`, not cryptographic erasure. `KMS_CRYPTO_ERASURE_NOT_IMPLEMENTED` remains a release blocker for a final-erasure claim.

Initialization checks the immutable migration checksum and catalog attestation before executing DDL/DCL. The catalog inventory also covers per-column `pg_attribute.attacl`; migration removes explicit runtime/PUBLIC column grants and verification rejects their return. PostgreSQL 18 JSON object cardinality is computed from `pg_catalog.jsonb_object_keys`, never a nonexistent helper. Later changes must use a new immutable migration in expand-migrate-contract order and preserve the current/previous contract-major compatibility window.
