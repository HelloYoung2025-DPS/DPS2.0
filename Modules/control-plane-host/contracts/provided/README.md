# Provided contracts

`control.plane.receipt/v1` is this module's deterministic receipt for accepted provider truth. Its contract pack includes the authoritative schema, strict bounded snake_case codec, and shared schema/codec adversarial corpus; missing, duplicate, additional, loose-ID, non-Zulu, malformed, or non-canonical external wire input fails closed.

`active.release.binding/v1` is the authoritative per-`device_binding_id` Release BOM read model. It carries the exact signed-BOM digest, a strictly monotonic runtime `generation`, the signer's `release_bom_generation`, the signer-committed opaque 256-bit execution token and its digest, and one of `active`, `previous`, or `revoked`. Runtime generation advances on activation and rollback; the signer ordinal must increase on activation but may truthfully revert when rollback restores the exact retained previous binding. The execution token is durable authority state, is never minted by Control Plane Host, and must remain redacted from text output.

`release.binding.receipt/v1` is the versioned append-only transition receipt for activation, revocation, and rollback. Activation and rollback advance runtime generation by exactly one. Revocation preserves the active BOM digest and generation while changing its state to `revoked`. Rollback may reactivate only the exact retained `previous` binding and consumes that rollback slot. The strict codec binds the per-device sequence, from/to endpoints, actor, timestamp, deterministic receipt identity, and canonical payload digest; unknown kinds, inconsistent endpoints, generation forks, or payload-digest drift fail closed.

The authority verifies externally signed canonical Release BOM bytes. A non-bootstrap activation also verifies and journals the exact externally signed `STABLE` lifecycle twin referenced by the candidate; it does not reconstruct, normalize, or sign that wire. Policy and executor consumers receive only the sealed authority-issued durable capability described in the operations guidance, so both paths observe one authority/store generation and token.

`action.execution.promotion/v1` is owned by `policy-approval`; Control Plane Host consumes that public contract pack and is its only allowed wire producer. The contract does not itself grant execution and does not replace an independent release approval, signature verification, policy evaluation, or human production approval.

The same ownership pattern applies to `approval.submission.reconciliation/v1` and `approval.submission.recovery/v1`: they remain Policy-owned API contracts while Control Plane Host is their only allowed wire producer. They are therefore registered as consumed owner contracts, not duplicated as Control-provided schemas.
