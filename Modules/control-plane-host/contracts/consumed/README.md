# Consumed contracts

The signed provider contracts are parsed from their exact owner schemas and current compatibility floors. `action.execution.promotion/v1`, `approval.submission.reconciliation/v1`, `approval.submission.recovery/v1`, and `approval.submission.state/v1` are owned by `policy-approval`; this module references that strict public contract pack and does not duplicate its schemas, DTOs, codecs, binding algorithms, or corpora.

Control Plane Host is the declared wire producer of reconciliation and recovery even though Policy owns their API contracts. It uses pairwise-distinct, strongly typed external signing capabilities, verifies each returned P1363 signature against the capability's canonical NIST P-256 public key, and dispatches through separate role-specific proposed port facades. The facades validate self-declared auth scopes, distinct credential-authority fingerprints, and bounded timeouts, but do not prove authenticated transport or process/credential isolation; production adapters that derive identity from actual mTLS, protected IPC, or equivalent Policy/database-role sessions remain unimplemented. The signed Policy state response is decoded by the owner codec, has its public commitment recomputed, is verified against the configured Policy-state authority, and must exactly match attempt, approval, proposal, command, lease, Soul, device, account, trace, idempotency, Release BOM, native binding, intent, predecessor, state, and evidence expectations.

The host consumes only the exact v1 results declared in `module.yaml`. It parses bounded strict UTF-8 bytes without importing provider implementation types, rejects duplicate/additional fields, binds canonical identity scope and lifecycle state, and verifies the producing module's P-256 signature against the current signed BOM/key trust revision before persistence. Platform-account alias-key and authorization-evidence metadata must use the provider-owned lowercase canonical grammar; mixed-case authority metadata fails closed. Contract tests bind the consumer parser directly to the provider-owned shared corpora at their canonical module paths; no provider fixture is copied or privately reinterpreted here. GBrain readback is a signed adapter proof whose declared checksums must match; this host does not possess the original GBrain bytes and therefore does not claim a local content-checksum recomputation.
