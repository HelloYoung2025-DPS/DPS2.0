- Added a machine-readable baseline for all 79 tracked legacy C# byte streams. Exactly three F1 false-green test repairs are separately named; every other path must remain byte-identical to `cac7ccbcce927a1a3a62cfd376497f0d30cc47e4`. Added adversarial tests for line-ending drift, unapproved changes, path injection, manifest self-approval, and symlink replacement. This remains static characterization only.

## Unreleased

- Added the dedicated `ERROR_BRIDGE_REQUIRED` failure token and cleared stale command payloads, success/action telemetry, legacy completion flags, queues, proposals, and memory projection state in SessionRunner and all seven production wrappers. Each optional-variable cleanup is isolated so one missing Zenno variable cannot skip the remaining fail-closed writes. The token follows the documented default-to-`BadEnd` route and is never written as `DONE`.

- Changed `SmartOrchestrator` to accept only raw exact `SUCCESS`; FAILED, TIMEOUT, UNKNOWN, garbage, whitespace-padded, and suffix-bearing success-like tokens fail before business postcondition and false-success accounting.
- Required an explicit expected page and an exact observed-page match before SmartOrchestrator can return success; missing or `unknown` postconditions now count as business failures.
- Replaced mutable/self-approving byte verification with a strict external-provider anchor. It binds fixed issuer/audience, UTC issue time, complete-record digest, Git commit/tree/parents, the exact 79-path inventory, original four plus separate eight containment repairs, explicit repair policy, verifier/rules/schemas/data, all test hashes, and protected minimum test counts of 21, 9, and 7. It rejects component collisions, case-aliased legacy roots/`Modules` children, and linked-directory hiding. Missing provider is `WAITING_EXTERNAL`; Windows and device evidence remain `NOT_RUN`.
- Pinned every required module verification command to an independent trusted-runner-created repository `.venv/bin/python` at CPython 3.12.13 instead of PATH `python3`; formal evidence must preserve interpreter SHA-256, exact argv, environment, raw output, and exit status.
- Added the F5 P0 SessionRunner containment boundary. All five production entrypoints now fail closed while the modern authorization bridge is unavailable; writable Step DSL auto-success, Vision ERROR-to-SUCCESS overrides, direct legacy execution/recovery, App Onboarder process launch, and unverified interaction-memory projection are blocked. Added exact-byte and source-shape regressions. Windows, ZennoDroid, ADB, device, canary, and release approval remain unverified.
- Made the SessionRunner stop path reassert `ERROR_BRIDGE_REQUIRED` before and after cleanup and isolated best-effort logging, preventing a logging exception from preserving a stale `DONE` route.
- Removed legacy result-token trimming and suffix extraction, so values such as `SUCCESS:detail` or whitespace-padded success cannot become `SUCCESS`; result-evaluation exceptions now return the failure token instead of `CONTINUE`.
- Replaced readable synthetic Golden Trace identities with canonical opaque IDs and added fail-closed case, length, legacy-format, and newline tests without touching byte-preserved legacy C#.
