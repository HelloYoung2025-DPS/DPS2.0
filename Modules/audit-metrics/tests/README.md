# Audit Metrics tests

Unit and Contract tests use a deterministic in-memory append store and prove duplicate/conflict handling, ordering, scope isolation, role checks, outcome preservation, raw PII/secret label rejection, domain-separated canonical-byte Golden Vectors, delimiter-collision resistance, and rejection of signature reuse against a different receipt.

The separate `Integration` suite requires `DPS_TEST_POSTGRES` pointing to PostgreSQL 18.4. It uses the concrete ECDSA relay verifier, a persisted highest-revision root-signed BOM/key source, an internal fixed test `TimeProvider`, independent migration/runtime login credentials, and real Npgsql transactions. Its eight executions cover invalid-signature and live revoked/key/BOM rotation zero-write behavior, including an uncommitted exclusive rotation barrier; concurrent duplicates; concurrent same-ID/different-digest and scoped-idempotency conflicts; restart and out-of-order readback; exact Soul/device/account event and quarantine isolation; `RESET ROLE` non-escalation; connection rejection after hostile table-ownership transfer; runtime DDL/mutation denial; owner-side update/delete/truncate triggers across event, quarantine, and trust history; event and quarantine crash windows; cancellation rollback; and safe retry. Missing PostgreSQL is a failed/not-run required check, never a skip or a simulated PASS. It is not Windows or device evidence.
